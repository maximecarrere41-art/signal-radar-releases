# 📡 Signal Radar

### Votre veille intelligente, automatisée et personnalisée

**Moins de temps à chercher. Plus de temps pour comprendre ce qui compte.**

Entre les sites d’actualité, les blogs spécialisés et les publications qui s’accumulent, il devient difficile de suivre ses sujets préférés sans y passer des heures. **Signal Radar** rassemble vos sources, sélectionne les informations pertinentes et vous aide à en retenir l’essentiel grâce à des synthèses personnalisées.

## ✨ Pourquoi Signal Radar ?

| Votre besoin | Ce que fait Signal Radar |
| --- | --- |
| **Tout suivre au même endroit** | Rassemblez vos flux RSS/Atom et découvrez les sources associées à des sites compatibles. |
| **Suivre les sujets qui vous intéressent** | Organisez votre veille avec plusieurs profils et leurs propres sources. |
| **Identifier les informations importantes** | Analysez les publications avec un fournisseur d’IA compatible et obtenez une sélection contextualisée. |
| **Lire l’essentiel rapidement** | Consultez des synthèses structurées, avec les sujets, leur importance et un résumé. |
| **Recevoir votre veille automatiquement** | Planifiez des analyses quotidiennes ou hebdomadaires et envoyez vos synthèses par e-mail. |
| **Garder une vue d’ensemble** | Retrouvez votre tableau de bord, l’état des services et l’historique des synthèses. |

## 🔎 Une veille qui s'adapte à vous

Que vous suiviez **l'intelligence artificielle**, la cybersécurité, le développement logiciel, l'économie ou les actualités d’un secteur, Signal Radar vous permet de choisir vos profils de veille et les sources à surveiller.

Ajoutez des sources RSS/Atom, testez leur disponibilité et gardez la maîtrise des contenus suivis. Lancez une nouvelle analyse à tout moment ou laissez votre planification s’en charger.

## 🤖 Des synthèses enrichies par l’IA

Signal Radar prend en charge **Gemini, OpenAI et Anthropic**, selon la configuration et les accès API de l’utilisateur. L’analyse permet de mettre en avant les publications pertinentes, leurs thèmes et leur importance.

Si un fournisseur IA est indisponible, l’application dispose d’un **mode de repli sans IA** pour continuer à produire une sélection. La qualité de l’enrichissement peut alors être différente.

## 📥 Installer Signal Radar sur Android

1. Ouvrez la **[dernière version disponible](https://github.com/maximecarrere41-art/signal-radar-releases/releases/latest)**.
2. Téléchargez le fichier **`.apk`** dans la section **Assets**.
3. Ouvrez le fichier téléchargé sur votre téléphone Android.
4. Autorisez l’installation depuis cette source si Android vous le demande, puis installez l’application.

## 🔐 Données, configuration et coût

- **Application Android gratuite**, sans achat nécessaire pour télécharger l’APK.
- **Données locales** : les profils, sources et historiques de l’application mobile sont stockés sur l’appareil, sans synchronisation entre appareils.
- **IA configurable** : les appels aux fournisseurs tiers nécessitent une connexion et peuvent être soumis à leurs propres quotas ou tarifs.
- **Envoi par e-mail** : nécessite la configuration d’un service SMTP.
- Les clés et secrets mobiles sont conservés dans le stockage sécurisé du système.
